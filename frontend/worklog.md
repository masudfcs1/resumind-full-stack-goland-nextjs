# AI Resume Builder — Work Log

Project: **ResumeForge AI** — A beautiful frontend-only AI Resume Builder (Next.js 16 + Tailwind 4 + shadcn/ui + framer-motion).

Planned routes (frontend only, no backend):
- `/` — Landing page
- `/dashboard` — Overview
- `/dashboard/builder` — Resume Studio (multi-step builder + live preview + PDF export)
- `/dashboard/resumes` — My Resumes
- `/dashboard/templates` — Template gallery
- `/dashboard/ats` — ATS Score scanner
- `/dashboard/grammar` — Grammar checker
- `/dashboard/cover-letter` — Cover letter generator
- `/dashboard/portfolio` — Portfolio website generator
- `/dashboard/linkedin` — LinkedIn import
- `/dashboard/settings` — Settings

Architecture (foundation owned by orchestrator):
- `src/lib/resume-store.ts` — Zustand store (persisted to localStorage), types, seed data
- `src/lib/mock-ai.ts` — Frontend "AI" simulation (summaries, bullets, ATS scoring, grammar, cover letters, LinkedIn parsing)
- `src/lib/use-mounted.ts` — hydration-safe hook
- `src/components/resume/resume-preview.tsx` — shared resume renderer (6 templates)
- `src/components/dashboard/shell.tsx` — dashboard sidebar/topbar shell
- `src/app/dashboard/layout.tsx` — dashboard layout
- Theme: emerald primary, zinc neutrals, light/dark via next-themes, Sora display font
